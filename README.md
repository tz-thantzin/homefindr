# HomeFindr

A premium real estate web application built with Flutter. Designed in a **luxury editorial style** — dark canvas, warm gold accents, and Playfair Display typography — inspired by high-end real estate brands like Sotheby's.

---

## Features

- **Buy & Rent listings** with filter by property type, beds, and sort order
- **Full-text search** with status and type filters
- **Property detail** pages with gallery, amenities, and agent contact form
- **5-language support** — English, Thai, Chinese, Japanese, Myanmar
- **Responsive** — desktop, tablet, and mobile layouts
- **Firebase Analytics** integrated; Firestore-ready repository layer
- **Subscription / pricing** section with monthly/yearly toggle

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Flutter (web primary) |
| State | Flutter Riverpod 3 |
| Navigation | GoRouter 17 |
| Backend | Firebase (Analytics + Firestore-ready) |
| Fonts | Playfair Display (headings) · DM Sans (body) |
| Localisation | ARB + `flutter_localizations` |
| Code gen | Freezed + json_serializable |

---

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run on web (primary target)
flutter run -d web

# Production build
flutter build web

# Regenerate Freezed / JSON models after edits
flutter pub run build_runner build --delete-conflicting-outputs
```

## Project Structure

```
lib/
├── core/
│   ├── constants/     # Design tokens (colors, sizes, mock data)
│   ├── extensions/    # BuildContext helpers (theme, responsive, padding)
│   ├── providers/     # Riverpod state (properties, locale, favorites)
│   └── router/        # GoRouter routes
├── data/              # Repository implementations (mock → Firestore)
├── domain/            # Models (Freezed) and repository interfaces
├── presentation/
│   ├── pages/         # Screens: Home, Buy, Rent, Search, Detail, Contact
│   ├── view_models/   # Thin provider wrappers consumed by pages
│   └── widgets/       # Reusable UI components
└── l10n/              # Localisation ARB files
```

## Environment

Create a `.env` file in the project root:

```
GOOGLE_MAPS_API_KEY=your_key_here
```

Firebase is configured via `lib/firebase_options.dart` (generated by FlutterFire CLI — do not hand-edit).
